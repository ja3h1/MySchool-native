# MySchool
WebView wrapper app for my school login portal.

1. Edit `PORTAL_URL` in `app/src/main/java/com/myschool/app/MainActivity.java`.
2. Open folder in Android Studio → Sync → Run. (Needs JDK 17, Android Studio does it.)
3. Push to GitHub → Actions tab → "Build APK" → download APK artifact.

## First commit
    git init -b main
    git add .
    git commit -m "Initial MySchool app"
    git remote add origin https://github.com/YOURNAME/MySchool.git
    git push -u origin main
